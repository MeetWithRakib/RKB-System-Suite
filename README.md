## About

**RKB System Suite** is an all-in-one Windows utility designed to help users maintain, analyse, repair, secure and optimise their PC from a single, clean interface.

| Focus | Tools |
|------|--------|
| **Performance** | Smart Boost, Process Manager, power plans |
| **Security** | Defender scans, quarantine, threat history |
| **Cleanup** | Temp/cache analyse and selective clean |
| **Repair** | SFC, DISM, CHKDSK, Winsock, TCP/IP |
| **Diagnostics** | System info, services, startup, network, DNS |

## Features

### Security
- Quick / Full / Custom Microsoft Defender scans  
- Quarantine manager  
- Defender status and threat history  

### Maintenance
- Smart PC Boost (manual, scheduled, RAM threshold)  
- Cleanup Center with size preview and selective delete  
- Large files, empty folders, duplicates, file hash checker  

### Repair
- System File Checker (`SFC /scannow`)  
- DISM CheckHealth / ScanHealth / RestoreHealth  
- CHKDSK, Flush DNS, Reset Winsock / TCP/IP  
- System Restore helpers  

### System
- Process Manager — CPU/RAM, filters, end, suspend/resume  
- Services Manager — search, bulk startup type, CSV export  
- Startup Manager  
- Scheduled Tasks  

### Network & privacy
- Adapters, connections, port listeners, firewall summary  
- DNS switcher (Cloudflare, Google, Quad9, DHCP reset)  
- Hosts file editor with backup  
- Privacy tools and USB history  

### Experience
- Back navigation inside tools  
- Pin / Unpin any sub-tool (Favorites)  
- Live tool search  
- Short explanation before a tool runs (optional “never show again”)  
- Auto-update when a new release is published

## Auto-update


Users are prompted when a newer version is available. The app downloads the update, replaces itself, and restarts.
